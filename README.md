### 🛠 What I Build

I specialize in networking, distributed systems, and infrastructure problems where downtime isn't an option. I'm most energized by problems that force you to think about the whole system: not just the application layer, but the networking, virtualization, database design, and deployment story underneath it. Whether it's architecting hybrid setups that span cloud and on-prem, building APIs that work in airgapped environments, or keeping distributed infrastructure reliable across regions, I like building things that have to actually work in production.

At **Viasat**, I built the primary control and management web tool and REST API for their Next Generation Modem (VEBEM) in three weeks, helped secure a **$250K product order**, and represented the team at **IEEE MILCOM 2025**. Previously did GN&C systems engineering on Trident II at **Charles Stark Draper Laboratory** and neutron scattering simulations at **NIST**. This summer, heading to **Oracle OCI**.

### 🔓 Open Source & Projects

I believe in open source as both a philosophy and a practice. Most of what I know came from reading other people's code, and contributing back is the least I can do. I contribute to **[SasView](https://github.com/SasView/sasview)**, a scientific small-angle scattering analysis tool used by neutron and X-ray researchers worldwide.

I also maintain my own projects: **[gopher](https://github.com/smalex-z/gopher)** is a public router we've been building from the ground up, tackling real problems in packet routing, NAT traversal, and network reliability. **[altsuite](https://github.com/smalex-z/altsuite)** is a self-hosted SaaS alternatives platform, because you shouldn't have to pay a monthly subscription for software you can run yourself. Both projects reflect the same principle: understand the system deeply enough to build it yourself.
